Temple of Time Statues.

A basic ReadMe for 4 of the Temple of Time Statues. They have in-game rigging. This is usefull for the 2 Statues types that have moving arms. Textures are not broken. The models uses mirror repeat tile texture mapping so if some parts of the textuing look off/bad this is why.

Tools:
Dolphin to extract the .arc files
yaz0dec.exe and/or rarcdump.exe: http://www.amnoid.de/gc/
Blender 2.78 with bdl/bmd import plug in: https://github.com/niacdoial/blemd Note: May now only work with Blender 2.80+
Switch Toolbox: https://github.com/KillzXGaming/Switch-Toolbox/releases Used to get emission textures with alpha layer intact.
